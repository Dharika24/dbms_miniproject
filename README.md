# Hotel Room Booking System

A menu-driven Python and SQLite mini project for managing hotel rooms, guests, bookings, booking charges, and cancellations. It demonstrates relational tables, primary and foreign keys, constraints, SQL joins, and basic database operations.

## Requirements

- Python 3

SQLite is included with Python; no third-party packages are required.

## Run

Open this folder in VS Code and run in its terminal:

```sh
python hotel_booking.py
```

The program creates `hotel_booking.db` and initializes three sample rooms on first run. Use the menu to view rooms, make a booking, view the booking register, or cancel a booking.

## Project files

- `hotel_booking.py` — application source
- `DBMS_Mini_Project_Hotel_Room_Booking_System.docx` — accompanying project report
- `screenshots/` — images included in the report

The application is a learning prototype. It allows one active booking per room and does not check overlapping booking dates.
